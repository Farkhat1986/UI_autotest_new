## Перезапуск упавших тестов

### Для перезапуска упавших тестов используется библиотека pytest-rerunfailures

* ### Для установки данной библиотеки применяется следующая команда:
```commandline
pip install pytest-rerunfailures
```

### Основные команды для перезапуска тестов, которые прописываются в терминале:

* ### Перезапуск осуществляется файлом pytest.ini
```commandline
[pytest]
reruns = 2
reruns_delay = 1
```
### В данном файле указано

* ### Повторить тест 2 раза, если он упал:
```commandline
reruns = 2
```
* ### Пауза 1 секунда между попытками:
```commandline
reruns_delay = 1
```

### Простой скрит для запуска упавших тестов 
```commandline
echo Запуск только упавших тестов из прошлого прогонa
pytest --lf
```

### Расширенный вариант скрита для запуска упавших тестов 
```commandline
echo == Первый прогон ==
pytest

echo == Повторный запуск только упавших тестов ==
pytest --lf
```
