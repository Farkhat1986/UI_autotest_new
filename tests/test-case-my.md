## Тест кейсы

## Тест кейс 1: Проверка перехода к странице Home с страницы Practice Site 2

**Цель:** Проверка настройки перехода на страницу Home
**Шаги:** 
	
1. Открыть сайт с главной страницей https://www.way2automation.com/
2. Найти меню вкладок Resources
3. Нажать на вкладку Practice Site 2
4. Нажать на кнопку Home

**Ожидаемый результат:** 
* Открытие главной страницы
* Нажатие на меню вкладок Resources
* Нажатие на вкладку Practice Site 2
* Переход на страницу Practice Site 2
* Нажатие на кнопку Home
* Переход на страницу Home
* Проверка заголовка главной страницы

## Тест кейс 5: Проверка перехода к странице практики с страницы Practice Site 1

**Цель:** Проверка настройки перехода на страницу практики
**Шаги:** 
	
1. Открыть сайт с главной страницей https://www.way2automation.com/
2. Найти меню вкладок Resources
3. Нажать на вкладку Practice Site 1
4. Нажать на кнопку ENTER TO THE TESTING WEBSITE на появившейся форме
5. Проверка формы Resizable

**Ожидаемый результат:** 
* Открытие главной страницы
* Нажатие на меню вкладок Resources
* Нажатие на вкладку Practice Site 2
* Переход на страницу Practice Site 2
* Нажатие на кнопку ENTER TO THE TESTING WEBSITE на появившейся форме
* Переход на страницу с практикой
* Проверка формы Resizable
